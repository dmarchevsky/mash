# MASH: status

Read `.mash/plan/progress.md` and display a summary of all features and their statuses.

For features showing `WIP`, also read the corresponding `.mash/dev/feature-<id>.md` and display the dev file status in parentheses (e.g. `WIP (DEV_DONE)`). If the dev file doesn't exist yet, show `WIP` only.

**After displaying the status, stop.**
