# MASH: config

> **Path note**: `.mash/` paths below are in the user's project directory (CWD), not in this framework's install directory.

Display current MASH settings and allow the user to change them.

1. If `.mash/plan/settings.md` doesn't exist, tell the user the project hasn't been initialized yet and suggest `/mash init`. Stop.
2. Read `skills/mash/shared/configure-settings.md` and follow its instructions.
3. **Stop.**
